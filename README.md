# Lluvia de Código

Verde fósforo sobre negro total, como si la realidad fuera una simulación.

Tema para [Kino](https://github.com/kinotvapp/kino-light). Cambia los colores, el fondo y las formas de toda la app, trae una pantalla de presentación y no se conecta a internet.

En Kino, escribe `kinotvapp/kino-theme-lluvia-de-codigo` en **Plugins ▸ Agregar un plugin**. Después ábrelo y pulsa **Activar**.

Cuesta 10 kinos, la moneda gratuita de Kino: se compra una vez y vale en todos tus aparatos.

Necesita Kino 0.9.81 o superior.
